== Description ==

Thêm biểu tượng "NEW!" vào tiêu đề bài viết mới.

== Installation ==

1. Tải lên thư mục plugin tới thư mục `/wp-content/plugins/`
2. Kích hoạt plugin thông qua menu 'Plugins' trong WordPress

== Frequently Asked Questions ==

= Làm thế nào để thay đổi số ngày hiển thị biểu tượng "NEW!"? =

Bạn có thể thay đổi giá trị của biến `$days` trong tệp `new-icon-plugin.php`.

== Description ==

このプラグインは、新しい投稿のタイトルに「NEW!」アイコンを追加します。設定した日数以内に投稿された記事のタイトルに「NEW!」が表示されます。

== Installation ==

1. プラグインのフォルダを `/wp-content/plugins/` ディレクトリにアップロードします。
2. WordPress のプラグインメニューからプラグインを有効化します。

== Frequently Asked Questions ==

= 新しい投稿として表示される日数を変更するには？ =

`new-post-icon.php` ファイル内の `$days` 変数の値を変更します。
